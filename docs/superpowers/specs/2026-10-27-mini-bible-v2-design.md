# Windows 초소형 성경 뷰어 V2 설계

## 목적

Windows에서 작은 창으로 사용자가 적법하게 보유한 개역개정 CSV 본문을 읽는 휴대용 성경 뷰어를 만든다. 본문은 배포하지 않는다.

## 목표

- 기본 창은 약 340×240px이며 설정에서 너비와 높이를 조절한다.
- 현재 절부터 기본 5절을 표시하고 표시 절 수를 3~5절로 설정한다.
- 성경 권·장·절 선택, 이전·다음 묶음 이동, 항상 위 토글을 제공한다.
- 글꼴 크기와 시스템·라이트·다크 테마를 설정한다.
- 마지막 위치, 창 크기·위치, 테마, 글꼴, 표시 절 수, 항상 위 상태를 복원한다.
- 사용자가 권한 있는 CSV를 가져오고 교체할 수 있다.
- 압축을 풀고 바로 실행할 수 있는 Windows x64 ZIP을 제공한다.

## 제외 범위와 실패 조건

- 저작권 보호된 성경 본문이나 대량의 실제 구절을 포함하지 않는다.
- 온라인 다운로드, 계정, 동기화, 검색, 주석·하이라이트는 V2에서 제외한다.
- CSV 오류로 종료되거나, 저장된 창이 화면 밖에 놓이거나, 테마 때문에 글자를 읽기 어려워서는 안 된다.

## 접근 방식

- 선택: .NET WinForms 자체 포함형 배포. 작은 창, 항상 위, DPI, 설정 저장에 적합하다.
- 미선택: Python/Tkinter는 패키지가 더 크고 시작이 느릴 수 있다.
- 미선택: HTML 기반 앱은 이 단일 목적 앱에 비해 런타임이 무겁다.

## 화면

- 상단: 권 콤보박스, 장·절 숫자 선택, 이동 버튼.
- 중앙: 읽기 전용 본문 영역. 절 번호와 본문을 줄 단위로 표시한다.
- 하단: 이전·다음, 현재 범위, 항상 위 토글, 설정 버튼.
- 설정 창: CSV 가져오기, 창 너비·높이, 표시 절 수(3~5), 글꼴 크기, 시스템·라이트·다크 테마, 기본값 복원.
- 최소 창 크기를 두고, 저장 위치가 모니터 밖이면 주 모니터 중앙으로 복구한다.

## 데이터

- 기본 헤더는 book, chapter, verse, text이며 권, 장, 절, 본문 한글 헤더도 인식한다.
- UTF-8 BOM 유무를 허용하고 인용부호와 쉼표가 든 본문을 올바르게 읽는다.
- 잘못된 행, 중복 구절, 필수 열 누락은 한국어 오류로 안내하며 기존 정상 데이터는 보존한다.
- 가져온 CSV를 사용자 로컬 앱 데이터 폴더에 복사한다.
- ZIP에는 실제 본문 대신 가상 예제 CSV와 형식 안내를 포함한다.

## 설정 저장

- 사용자별 로컬 앱 데이터 폴더의 JSON 파일에 저장한다.
- 파일이 없거나 손상되면 안전한 기본값으로 실행한다.
- 본문이 없는 첫 실행에서는 가져오기 안내를 표시한다.

## 검증

- CSV 파싱, 헤더 별칭, 정렬, 중복·오류, 묶음·장 경계 이동, 설정 저장·복원을 자동 테스트한다.
- Release 자체 포함형 Windows x64 빌드와 ZIP 생성을 확인한다.
- 실행 파일에서 기본 창, 설정, CSV 가져오기, 테마, 항상 위, 재실행 복원을 확인한다.
- ZIP을 별도 임시 폴더에 풀어 실행 가능 여부를 다시 검사한다.

## 구현자 판단

- 색상과 여백은 340×240px에서 읽기 쉬운 중립적 디자인으로 정한다.
- .NET SDK가 없는 PC에서도 실행되도록 자체 포함형으로 게시한다.
