# 절 간격 축소 설계

## 의도

본문의 각 절 사이에 현재 들어가는 한 줄짜리 빈 공간을 줄여, 작은 창에서 더 많은 내용을 읽으면서도 절 경계를 쉽게 구분한다.

## 동작

- 절과 절 사이의 이중 줄바꿈을 제거한다.
- 각 절 문단 뒤에 현재 본문 글꼴 한 줄 높이의 약 50%에 해당하는 문단 간격을 적용한다.
- 사용자가 글꼴이나 글꼴 크기를 바꾸면 간격도 비례해 바뀐다.
- 새 장의 굵은 장 제목은 본문 절보다 분명하게 구분되는 기존 여백을 유지한다.
- 본문 텍스트, 장 제목, 굵기, 스크롤 이동 동작은 바꾸지 않는다.

## 접근 방식

- 선택: RichTextBox 문단 서식을 사용해 절 문단의 뒤 간격을 지정한다. 반 줄 간격을 정확히 표현하고 글꼴 크기에 비례한다.
- 미선택: 줄바꿈을 한 번만 넣는 방식은 간격이 거의 없어 절이 붙어 보인다.
- 미선택: 공백 문자나 빈 줄의 글꼴만 축소하는 방식은 선택·복사 시 불필요한 문자가 섞이고 글꼴에 따라 결과가 흔들린다.

## 검증 및 버전

- 절 사이에 빈 문단이 생기지 않는지 자동 검사한다.
- 절 문단에 양수의 반 줄 간격이 적용되는지 자동 검사한다.
- 장 제목과 기존 화면 기능의 전체 검사를 다시 실행한다.
- 프로그램 및 배포 버전을 V2.10으로 올린다.
