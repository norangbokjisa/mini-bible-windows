미니 성경 변경 내역
===================

V2.10 (2026-10-29)
- 같은 장의 절 사이 빈 줄을 제거하고 약 반 줄의 문단 간격 적용
- 본문 글꼴 크기에 따라 절 간격도 자연스럽게 비례하도록 개선
- 새 장의 굵은 장 제목 구분 간격은 기존 방식 유지

V2.9 (2026-10-29)
- 선택한 성경 권의 첫 장·첫 절로 이동하는 '첫장 가기' 버튼 추가
- 장·절 위/아래 조절 버튼을 좌우 화살표 방식으로 교체
- 장·절 숫자 직접 입력 기능 유지
- 새 메뉴 폭에 맞춰 최소 창 크기와 자동 줄바꿈 높이 조정

V2.8 (2026-10-28)
- 장·절 입력칸 가로 폭 확대
- 이동 버튼과 절 입력칸 사이에 10px 간격 추가
- 다크 모드에서 이동 버튼을 진한 회색 배경과 흰색 글자로 표시

V2.7 (2026-10-28)
- 성경 선택 드롭다운 스크롤바에도 다크/라이트 테마 적용
- 긴 성경 이름이 잘리지 않도록 선택값과 드롭다운 폭 확대
- 하단 성경 위치를 왼쪽, '항상 위'를 오른쪽에 고정
- 하단 성경 위치 글꼴을 보통 굵기로 변경

V2.6 (2026-10-28)
- 상단 메뉴가 한 줄일 때 메뉴 영역이 불필요하게 두껍게 남는 문제 수정
- 두 줄 메뉴일 때만 상단 높이가 자동으로 늘어나도록 개선
- 본문 스크롤바에 다크/라이트 테마 적용

V2.5 (2026-10-28)
- 최초 실행 및 높은 화면 배율에서 상단 메뉴가 가려지는 문제 수정
- 좁은 창에서는 상단 메뉴가 자동으로 두 줄 배치되도록 개선
- 메뉴가 가려지지 않는 창 최소 크기 적용
- 하단 '항상 위' 체크박스를 오른쪽 끝에 고정

V2.4 (2026-10-28)
- 다크 모드에서 앱 상단 메뉴와 Windows 제목 표시줄도 어둡게 표시
- 긴 성경 이름이 보이도록 성경 선택 목록 폭 확대
- 구약/신약 선택 버튼 및 권 목록 필터 추가
- 상단 필터와 본문 사이의 간격 확대
- 본문 좌우에 10px 여백 추가

V2.3 (2026-10-27)
- 높은 화면 배율에서도 설정 창 하단 버튼 글자가 잘리지 않도록 버튼과 창 크기 개선
- 본문에서 성경 이름을 매 절마다 반복하지 않도록 변경
- 장이 바뀌는 지점에만 굵은 '성경 이름 N장' 제목 표시
- 각 절은 'N. 성경말씀' 형식으로 표시

V2.2 (2026-10-27)
- 설정 창 하단이 잘리는 문제 수정
- 다크 테마가 버튼, 입력창, 본문에 적용되도록 개선
- 설치된 Windows 글꼴 선택 기능 추가
- 한 화면 표시 절 수 범위를 1~10절로 확대
- 각 본문 앞에 성경 이름과 장·절을 표시하고 굵게 강조
- 프로그램 제목과 배포 파일에 버전 번호 표시

V2.1
- 성경 권·장·절 선택 메뉴 확대
- 마우스 휠 한 절 이동 추가
- 설정 버튼을 상단 톱니바퀴 버튼으로 변경
- 하단 구절 범위 글자 확대
