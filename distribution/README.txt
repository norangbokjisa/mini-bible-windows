미니 성경 V2.9
===============

1. 실행.cmd를 더블클릭합니다. 이미 .NET 9 Desktop Runtime이 설치되어 있다면 MiniBible.App.exe를 직접 실행해도 됩니다.
2. 처음 실행할 때 또는 설정의 JSON/CSV 연결을 눌러, 본인이 적법하게 사용할 권한이 있는 성경 JSON 또는 CSV를 선택합니다.
3. 권·장·절을 선택하거나 본문 위에서 마우스 휠을 굴려 한 절씩 이동합니다.
4. 오른쪽 위 톱니바퀴(⚙) 버튼을 누르면 설정 창이 열립니다.
5. 설정에서 창 크기, 한 번에 표시할 1~10절, 글꼴 종류와 크기, 시스템/라이트/다크 테마를 바꿀 수 있습니다.
6. 항상 위를 켜면 다른 창보다 위에 유지됩니다.
7. 본문은 절 번호로 표시하며, 새 장의 1절 앞에만 굵은 장 제목을 표시합니다.
8. 상단의 구약/신약을 선택하면 해당 성경 권만 목록에 표시됩니다.
9. 창을 좁히면 상단 메뉴가 자동으로 두 줄로 바뀌며, 메뉴가 가려지지 않는 최소 크기 아래로는 줄어들지 않습니다.
10. 한 줄 메뉴에서는 상단 영역도 한 줄 높이로 줄어들며, 스크롤바 색상은 선택한 테마를 따릅니다.
11. 하단에는 현재 성경 위치가 왼쪽, '항상 위'가 오른쪽에 표시됩니다.
12. '첫장 가기'를 누르면 선택한 성경 권의 첫 장·첫 절로 이동합니다.
13. 장과 절은 좌우 화살표로 조절하거나 가운데 숫자를 직접 입력할 수 있습니다.

JSON 형식
---------
UTF-8 JSON 배열에서 각 항목은 다음 속성을 사용합니다.

{"book":"가상권","chapter":1,"verse":1,"text":"가상 본문"}

한글 속성 권, 장, 절, 본문도 지원합니다. sample_bible.json을 참고하세요.

또한 "창1:1": "본문"처럼 성경 약칭과 장·절을 키로 사용하는 단일 JSON 객체 형식도 지원합니다.
예: {"창1:1":"가상 본문","창1:2":"가상 본문"}

CSV 형식
--------
CSV도 계속 지원합니다. UTF-8 CSV 파일의 첫 줄은 다음 둘 중 하나여야 합니다.

book,chapter,verse,text
권,장,절,본문

본문에 쉼표, 따옴표 또는 줄바꿈이 있으면 표준 CSV 방식으로 큰따옴표를 사용하세요.
샘플 파일은 형식 확인을 위한 가상의 문장만 포함하며 성경 본문이 아닙니다.

설치
----
이 배포본은 전용 .NET 런타임을 dotnet 폴더에 포함합니다. PC에 .NET이 설치되어 있지 않아도 실행.cmd로 별도 설치 없이 실행할 수 있습니다.

저작권
------
이 프로그램에는 개역개정 또는 기타 저작권 보호 성경 본문이 포함되어 있지 않습니다.
사용자는 본인이 이용 권한을 가진 JSON 또는 CSV만 가져와야 합니다.
